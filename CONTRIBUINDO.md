# Como contribuir

Obrigado por querer contribuir com o `meu-terceiro-repo`!

1. Abra uma issue descrevendo o problema ou a sugestão, para que possamos conversar antes.
2. Crie uma branch a partir da `main`, com um nome descritivo (por exemplo, `docs/minha-melhoria`).
3. Faça suas alterações e commits com mensagens claras.
4. Envie a branch para o repositório e abra um Pull Request para a `main`.
5. Aguarde a revisão e ajuste o que for pedido até a aprovação.
